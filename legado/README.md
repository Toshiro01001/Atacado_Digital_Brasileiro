# Projeto acadêmico original

`ProjetoN3/` é o trabalho acadêmico que deu origem a este sistema: páginas em HTML e CSS, simulação de login e scripts SQL. Fica aqui como registro. O sistema atual está na raiz do repositório.

Ao mover para esta pasta, foram retirados da versão atual: a senha escrita em `Cadastros/admin.html`, os CPFs e senhas de exemplo de `SQL/CADASTRO.SQL`, a senha de `SQL/INICIO.SQL`, os CNPJs de `SQL/FORNECEDORES.SQL` e os nomes de marcas reais de `SQL/PRODUTOS.SQL`. Cada página ganhou no topo um aviso de sistema de demonstração, porque o GitHub Pages também publica esta pasta. O restante está como foi entregue, inclusive os erros: as páginas usam caminhos absolutos e os arquivos SQL contêm sobras de Python. As correções estão descritas em `sql/README.md`.
