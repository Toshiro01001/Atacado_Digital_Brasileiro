Como isto funciona

Isto é um sistema de atacado de verdade, só que com dados inventados. O banco de dados é um arquivo SQLite que roda dentro do seu navegador, por meio de WebAssembly. Nada sai do seu aparelho.

O que acontece quando você fecha um pedido

O sistema abre uma transação: cria o pedido, calcula o preço pela faixa de quantidade, desconta o estoque só se ainda houver saldo e registra a movimentação. Se qualquer passo falhar, tudo é desfeito. A faixa no rodapé da tela e o console SQL mostram os comandos reais.

Duas camadas, o mesmo banco

Esta página é a versão que roda em hospedagem simples, como o GitHub Pages, que não executa PHP. O repositório traz também a versão de servidor: PHP 8 com PDO, API em JSON, login com senha protegida por hash e banco SQLite ou MySQL. As duas usam os mesmos arquivos SQL.

O que dá para adaptar ao seu negócio

  • Catálogo, departamentos, unidades e faixas de preço por quantidade.
  • Pedido mínimo, condições por cliente e etapas do pedido.
  • Painel do gestor com os indicadores que você acompanha.
  • Integração com emissão de nota, boleto ou Pix, feita no servidor.

Aqui, cada navegador tem o próprio banco. Para vários usuários compartilharem os dados, usa-se a versão de servidor.
