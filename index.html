Como isto funciona

Este site é um exemplo de loja de atacado, daquelas em que uma empresa compra de outra em grande quantidade. Tudo aqui é inventado: as empresas, os produtos, os preços e os pedidos. Nada é vendido nem cobrado de verdade.

Você pode usar sem medo: escolha produtos no Catálogo, feche um pedido e veja o resultado nas abas Histórico e Gestor. Se quiser começar de novo, a aba Gestor tem o botão "Restaurar dados de exemplo".

O que acontece quando você fecha um pedido

O sistema grava o pedido, calcula o preço pela quantidade comprada (quanto mais unidades, menor o preço de cada uma), desconta os itens do estoque e anota essa movimentação. Tudo isso acontece de uma vez só: se algum passo falhar, nada é gravado pela metade.

Onde ficam os seus dados de teste

Tudo fica guardado só no seu navegador, neste aparelho. Nada é enviado para a internet. Por isso, cada pessoa que abre o site vê a própria loja, e o que você fizer aqui não aparece para mais ninguém.

O que dá para adaptar ao seu negócio

  • Catálogo, departamentos, unidades e faixas de preço por quantidade.
  • Pedido mínimo, condições por cliente e etapas do pedido.
  • Painel do gestor com os indicadores que você acompanha.
  • Integração com emissão de nota, boleto ou Pix, feita no servidor.
Detalhes técnicos

O banco de dados é um SQLite real que roda dentro do navegador, por meio de WebAssembly (sql.js). Ele é salvo no IndexedDB do navegador depois de cada gravação. A tela não chama nenhum servidor.

Fechar um pedido abre uma transação: INSERT do pedido, cálculo do preço pela faixa de quantidade, UPDATE condicional do estoque (só desconta se ainda houver saldo) e registro da movimentação. Qualquer falha gera ROLLBACK. A faixa no rodapé e o Console SQL mostram os comandos reais.

Esta página é a versão para hospedagem estática, como o GitHub Pages, que não executa código de servidor. O repositório traz também a versão de servidor: PHP 8 com PDO, API em JSON, login com senha protegida por hash, token CSRF e banco SQLite ou MySQL. As duas versões usam os mesmos arquivos SQL. Para vários usuários compartilharem os mesmos dados, usa-se a versão de servidor.
